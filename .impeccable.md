## Design Context

### Users
Security reviewers examining API scans, checking evidence and endpoint coverage, and configuring subsequent runs.

### Brand Personality
Restrained, clear, practical. Help reviewers understand the evidence and retain control over scan execution.

### Aesthetic Direction
Keep the current style, as confirmed by the user: light-first surfaces, existing typography and color tokens, with an explicit dark theme. Use the scan configuration sidebar as the reference for related workspaces.

### Design Principles
- Give long endpoint paths and explanations enough space to read.
- Group related scan tasks in a sidebar with one focused content area.
- Preserve keyboard navigation, mobile access, and state when switching panels.
- Keep verified evidence distinct from heuristic leads and preserve explicit run authorization.
